# Audit — camsilo (camsilo.dk) (2026-06-14)

**Stack:** Next.js 15 (App Router) · React 19 · TS · plain CSS · **ingen DB** (analytics = daglige NDJSON-filer, contact-beskeder = atomisk JSON, begge under `DATA_DIR`). Marketing one-pager + password-beskyttet `/admin` (analytics + contact-inbox + "Odin" mail-command-center). Integrationer: PostStack, Web Push (VAPID), Discord/Slack-webhook, GA4. Deploy: HostStack fra GitHub `camsilo/camsilo`. **Repo er endnu untracked.**

**needs-a-big-hand: 1/5** — sund, sikkerhedsbevidst lille static site.

**Verifikation:** `npm run typecheck` → **PASS** (rent). Ingen test-script. `npm audit`: 0 critical/high, **2 moderate** (begge transitiv `postcss` XSS via Next, build-time only — fix kræver Next-downgrade, lad være).

**Stærke sider:** admin-session = HMAC-SHA256-signeret httpOnly-cookie m. `timingSafeEqual`, self-expiring `iat`, `ADMIN_SESSION_EPOCH`-revocation, `secure` i prod, `AUTH_SECRET` mandatory i prod. Inbound-webhook token-gated (constant-time). Inbound mail-HTML strippes til tekst (ingen XSS). Email-regex blokerer mailto-injection; Discord/Slack neutraliserer `@everyone`. Fil-writes bruger faste/derived paths (ingen traversal). Stærke security-headers (CSP/HSTS/X-Frame DENY). Ingen secrets committet.

---

## MEDIUM

- **`laesHaendelser` linear-scanner alle NDJSON-linjer pr. `/admin`-load** (`analytics/store.ts:74-120`) — med `force-dynamic` admin + 120-dages retention er det en unbounded scan der vokser m. trafik.
  - **Fix:** Pre-aggregering/caching hvis analytics-volumen vokser.

## LOW

- In-process rate-limit/login-counters (`admin/actions.ts:31`, `api/hit/route.ts:15`, `api/kontakt/route.ts:19`) — pr. instans, resetter ved redeploy. OK ved single-instance; brækker ved horisontal skalering på HostStack.
- Client-IP-trust afhænger af host-header (`lib/klient-ip.ts`) — TODO at verificere HostStacks real-client-IP-header; worst case degraderer til global rate-limit (ingen bypass).
- Fire-and-forget `notificer`/`sendPush` (`api/kontakt/route.ts:150`) — intentionelt, men notifikations-fejl er tavs.
- `erSpam`/spam-score-tærskel duplikeret (`api/inbound/route.ts:58` + `AdminEmail.tsx:45`) — drift-risiko.
- Flat-file storage er volatil uden persistent disk — verificér `DATA_DIR` peger på disken i prod, ellers resetter analytics/beskeder ved redeploy.
